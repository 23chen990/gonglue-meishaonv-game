# 四女主 r4：不可随意改动的运行契约

唯一正式作者源是 `data/STORY.json`、`EPILOGUES.json`、`BONUS.json`、`CODA.json`、`HANDBOOK.json`。`play.html`、`runtime.mjs`、`repository-index.html`、完整 Markdown 与选择台账都由工具生成。不要编辑生成物来“修复”游戏。

## 状态、命令与渲染
入口 `createState()`；`renderScene(state, data)` 只读显示；`choose(state, data, choiceId, expectedRevision)` 返回新状态及回应。回应条件按点击前状态判断；之后才应用效果。`replay(data, commands)` 从 ENTRY_WAKE 重放，不接受任意终局状态。日志里的 from 和显式 revision 不匹配必须报错。未知条件、未知效果、不可选按钮、陈旧命令不得默默接受。修改任何解释器规则后必须重跑普通输入见证，而不是只对最终结局 ID。

## 关系不是一个好感分
interest、active、scope、commitment、reciprocal、pending、latent、breach 分别表示兴趣、关系是否存在、范围、承诺、双方意愿、待解决问题、未发现谎言和已发生冲突。四个 SPARK 场只改变早期兴趣及真实选择记忆，不给予 active/scope/commitment。慢热、朋友、拒绝与分开不能互换。每人独立同意后才能形成多角关系，共同活动和知情不能替代同意。

## 记忆与知识
正文只能回忆真实选择及物件。看到场景不等于拍照、接吻、拿到授权或取得母带。半成品试听不等于完整母带。sources 按具体人物、具体事实和实际命令记录；玩家知道原著，不代表人物也知道。收藏和旧周目不会给本周目增加知识。修复必须对应同一问题编号，完成承认、具体行动与重新协商，不能拿一次旧道歉抵消后来的新谎言。

## 日程与命运
20个自由日程保留。同次外出的连续两段都实际播放和选择；不得无条件 stage+2。三/四人活动推进相处，但不直接确认任何人的恋爱关系。早期 plan 只提供机会；EXEC、后来真实取得材料与 RES 形成命运因果。E01 等非恋爱材料允许独立自救，没有录音时不得演出播放原声。

## 阅读器与存档
存档键 `gonglue:revision-r4:canonical`，以引擎版本与正式剧情 SHA 隔离；旧 r2 和旧双女主键不删除、不静默迁移。`profile` 是收藏，不是当前世界。回看只读，历史重新选择才回滚事实并舍弃后续命令。存档冲突不能静默覆盖另一标签页。失败时保留内存进度、显示未保存、允许导出和明确恢复。损坏记录先备份再重开。

输入保护应拒绝同一渲染/版本上的重复点击、滚动手势和陈旧按钮，但不得吞掉新页面上不同按钮的合法点击。按钮至少44px，正文自然流分页，可滚动到达，大字与横屏都需检查。

## 验证边界
`test-conditional-r3.mjs` 统计真正显示的正文/已选回应，不把未选选项的真条件算成播放。565/565是文本块见证，不是穷尽状态空间。真实 HTTP、原生 localStorage、真实浏览器进程重启由原生浏览器套件验证；模拟存储和 set_content 只能叫离线证据。CI不是手机硬件，更不是真人留存。

## r4开场不可破坏的因果

先头晕苏醒，再借现场称呼与工作证识别身份，然后认出小说，再缓过神寻找蓝标盘。只有阿衡实际试听后，`source_blue_disc`/`blue_audio_checked`才成立。首三次按钮是认知过程，不假装是三次改命选择。真正首次分支在COLD。

五个救场方法分别有`opening_method`与A2b回调。许照没有按控台；后来的造假录像必须删去阿衡切换的部分来误导，不能凭空换一种事故过程。原著第十三章是第七天许照被清退，不是已核实的首演章号。

`qa/current/scene-editorial-audit.json`是作者第二轮自查。独立外部QA或真人盲测没有发生，不能改名为独立玩家验收。
