4. **REA 项目官方说明**：https://github.com/morluto/rea 。其 README 中介绍 `npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json` 的 JS 研究方式，和通过 `npx rea-agents setup` 为 Codex 注册 MCP。**本次未在当前环境调用 REA**，因此没有竞争产品运行时抓取证据。

## 实作的 UX 验收重点（与竞品研究结论分开）

- 场景主导，人物、背景和对白处于固定竖屏，而非无限网页卡片；120px 以下视觉边界不应隐藏真正动作。
- 已经讲完最后一句就直接显示选项，不能用“现在到你选了”“进入选择”制造额外点击。
- 一个语义问题 2–3 种做法为主、最多 4；后期任务过多按“目的”分级，不是依序藏在下一页。
- 首 28 节拍先建立穿书、原著主角和自己的坏结局；**这段是用户要求的真实故事先于第一个决定的例外**，不能再简写成可选折叠。
- 原著记忆必须出自主角第一人称内心，而非系统浮窗；所有情节变量只能引用真正获得的信息、物品或人物授权。
- 文字滑动不能误点选项；切换意图分类不记剧情命令，真正点击才记录命令；底层能用存档/回退准确复现。
- 美术与声音是原创候选资源，并非易次元或橙光截图、程序、立绘的照搬。
