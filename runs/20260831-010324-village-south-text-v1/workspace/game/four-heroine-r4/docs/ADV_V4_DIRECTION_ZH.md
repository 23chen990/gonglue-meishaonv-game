# 《攻略美少女》ADV V4 导演与移动端硬规范

版本：2026-10-16 / 适用 Draft PR #20 / **不是主线剧本改写**。本版把叙事源码保留在 DATA/STORY.json，通过导演层改变展示顺序、对白表演、镜头和视觉焦点；实际选择仍交给原故事引擎和存档回放。不能把“原文未全部显示”误当成剧情被删除：历史记录仍需可回看。但也不能把导演层改写误报为已完成全 228 场人工剧本改稿。

## 体验方向与竞品对照结论

以经典 ADV 视觉小说为主，参考《Summer Pockets》《苍之彼方的四重奏》《ATRI》等的“场景背景、前景人物、一次一句当前对白、真正抉择才出现选项”的视觉语法。借鉴这些作品的叙事层级，不复制素材、比例或假设其移动端交互实测。我们做的是竖屏适配，而非把手机屏幕变成小说阅读器、PPT 道具卡或抽卡角色筛选页。

## 前 30 秒导演时间线（设计目标，**不是**已测真人阅读速度）

| 预期窗口 | 镜头 | 这一屏必须让玩家知道什么 | 台词/输入 |
|---|---|---|---|
| 0–3 秒 | 演出后台近景，普通戴耳麦工作人员迎面俯身 | 有人叫我“许照”，很着急 | 阿衡：“许照！醒醒！马上就要开唱了！” → 点击 |
| 3–6 秒 | 仍为工作人员近景，玩家主视角 | 我和他不认识 / 身份错位 | 主角：“……你在叫我？” → 点击 |
| 6–10 秒 | 第一视角：我手里确实攥着工作牌，能辨认“许照”“临时场务” | 我不是原来的自己 | 主角：“许照……临时场务？这不是我的名字。”；点击工作牌可放大看 |
| 10–15 秒 | 舞台女孩耳返出问题，琴台亮起 | 版本被换、演出近乎开始 | 女孩：“停！这不是我排练的版本！”；男声：“我用钢琴撑四小节！” |
| 15–21 秒 | 依次切两镜：林见月举相机；顾晚棠核邮件 | 这些人和小说中的名字对应 | 画面主导，不显示人物抽卡卡片，不让玩家先选女主 |
| 21–26 秒 | 临场紧张特写 → 器材旁蓝标 U 盘线索 | 我记得七天后的背锅结局；眼前存在可行动的线索 | 一句内心独白即可；不要七段原著解释 |
| 26–30 秒 | 琴台全景，三个短行动选项 | 玩家可以当场改变接下来发生的事 | 直接行动：先看交接记录 / 拿原版 / 拿原版并留证 |

**切勿根据此表强制自动播放**。玩家点击推进，阅读时间因人而异。首次有后果的真实选择是 canon / rescue / investigate，不能为了凑“互动次数”添加仅改变文案的伪分支。

## UI 硬性规则（手机 320×568 到 430×932，兼顾字体放大）

1. 普通 ADV：背景/CG 占大多数画面；对白框正常高度目标约 1/4 屏，短屏与大字最多 1/3。一次只出现一个角色的一段当前对白。
2. 台词：短句 1–3 行。字装不下就由播放器原有的 measured-grapheme 分页与“继续”逐段展示；不可缩字硬塞，不可出现对白框内纵向滚动，不允许把旧文和新文累积成滚动小说。
3. 名字牌：对应当前**说话人**。第一次未确认身份的男性使用“戴耳机的男人”，钢琴男声使用“钢琴旁的男人”，舞台女孩在正式介绍前使用“台上的女孩”；主角说话“许照”，心声“许照 · 心声”。
4. 道具发现：必须是第一视角照片/CG 里的手与实体物品，而不是 CSS 拼出来的平面说明卡。玩家可以轻触道具查看；这个动作只打开特写，绝不误执行剧情选择或推进两页。
5. 人物相遇：镜头一次聚焦一个人，有明确出场地点与行为；多角色同场可以并置人物，但不能用商店式“双排女主卡片”代替演出。女主脸部不能莫名弹成插画列表。
6. 选择：只有真实引擎允许时才显示；选项用第一人称的**说话/行动**，不采用“保留证据策略：判定道德立场”之类摘要文字；重要后果保留在真实选择 ID 内，UI 不能通过选项排序改写规则。
7. 视觉与素材：CG 和立绘必须由统一的图像素材提供。严禁 SVG/CSS 画人物、假工牌、假 USB、示意杯子等替代演出；CSS 仅负责排版、氛围渐变、可访问性、焦点与蒙层。当前 CG 是针对试玩制作的新素材，不代表已完成最终资产授权与风格统一评审。
8. 通用播放器：不出现常驻的剧情进度提示条、教学卡、巨大半透明浮层。剧情推进行为须可以点击对白区或明确“继续”。菜单和历史单独存在。
9. 可访问性：真实按钮最小 44px；选择触屏不误触；关闭特写返回**同一源文本和偏移**；支持 reduced-motion、屏幕阅读标签和独立字号设置。
10. 不虚报验收：Chromium 页面模拟与源码测试不是 iPhone/Android 真机，也不证明前 30 秒留存，更不证明 228 场都已经具备完整镜头素材。

## 资产说明

`assets/v4/scene_*.webp`：基于原创图像生成素材裁切与合成，和仓库已有的 backstage CG 背景做摄影式羽化，不使用程序绘画角色和物件。`pov_badge.webp`、`usb_case.webp`、`usb_hand.webp` 是用于点击放大查看的照片裁切。正式量产前仍需重新审查全部画面的人物一致性、版权/商用许可及分镜构图，不可把 AI 画面的文字作为关键剧情唯一证据。

## 重要内容约束与回归

- 引擎、DATA、choices ID、effect、结局与已保存命令不能改。`ENTRY_WAKE` 原 28 段正典保持；导演层精选约 11 次场面转移到第一次选择，删掉的屏幕解释可在历史查看。
- 三条开场分岔 canon / rescue / investigate 全可选，点击后继续使用正式引擎。
- 正式运行需检查：所有支持的手机宽度，小屏三选项同屏；角色与说话人的一致性；每条选项触发后续场景；点击工作牌放大与关闭不会改剧情状态；旧存档恢复不跳错；打开菜单返回不改变当前源文本；Chromium/WebKit（若环境可用）及实际手机盲玩分别验收。
- 后续 228 场的导演覆盖不能仅靠正则自动缩写来冒充人工完成；至少按场景类型分桶，逐场记录“人物在场、镜头、可点击物、台词、选项反馈”，先完成前十分钟真实盲玩，再扩展全局。
## V4.1 电影化演出与历史光标保护

- 前 10 次点击展示有意义的台词、人物与行动；第 11 个节拍进入真实选择界面。此为工程节拍，不等于真人 30 秒完成或确认有留存。
- 戴耳机的现场人员实际入镜；许照低头看到自己手中工作牌；林见月和顾晚棠在各自场景发声，没有旧版双排人物卡。
- 原版 U 盘不可在玩家选择“去找”之前作为已拿到的物品出现；选择保留原著事件走向时，不能显示已拿到原版的照片，分支后果由真实引擎决定。
- 菜单切换大字号、关闭道具特写后，原 source-row 位置不丢失。Chromium/WebKit 均须通过自动化回归；不能把跳过剧情误判为分页优化。
- 主舞台尽量只显示剧情 CG；轻量菜单悬浮于画面上，对白半透明而易读，历史仍保留原著的 28 条开场内容。尚未完成 228 场逐幕导演与真人首 30 秒留存测试。
