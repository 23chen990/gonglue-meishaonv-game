# 恋爱 V9 一次性整合｜2026-10-17

## 修改范围
在 ADV8 完整事件 CG 基础上，增加真实正典选择后的**分支镜头回应**和四位女主不同的开场亲密对话。所有剧情结果仍由原 `STORY.json` 的正典 `choose()` 产生：展示层不直接写好感、不虚构属性、不修改结局逻辑。

* `rescue`：原版盘到手 → 唐映雪示意接歌；`investigate`：盘与证据 → 沈清辞核对；`canon`：钢琴接场 → 程放逼签。三条分支都是两段**短对白 + 对应独立 CG**，并在原引擎回复后、第二次真实选择前出现。
* 唐映雪、沈清辞、林见月、顾晚棠各有两句鲜明但简短的初次私下交流，然后显示对应的三个真实剧情选项。原引擎的后续回复和存档保持不变。
* 同图相邻对白不会重复播放镜头入场动画，避免用户点一下就闪一次。

## 技术与验收
* 快速单人对白；底框不超过屏高 1/3；真实按钮触点至少 44px；关掉重复的小说旁白提示。
* V9 交互进度记录于 `ui.emotionV9`，不进入 canonical `commands`。旧存档不含该字段时直接跳过新回响，不强迫老玩家重看。
* 回到菜单、刷新或旧剧情记录时不会生成额外正典命令；首选后两段回响可恢复；四位女主的前置对话仅 UI 状态，真实抉择记录由引擎提供。
* `tools/test-interactive-opening.py` 校验 3 条分支即时回响；`tools/test-romance-v9.py` 在两浏览器走 4 位女主完整路线并核验存档、实际选项及对话溢出。
