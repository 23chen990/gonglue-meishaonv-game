# ADV V5｜单镜头 Galgame 舞台

本次针对实际玩家截图中的“半透明工作人员”“漂浮工作牌”进行根因修复，而非给拼接图加遮罩。设计验收对象必须是 **真实 H5 渲染截图**，而非生成的概念海报。

- 一次只呈现一张真实完整剧情 CG：背景和人物属于同一张未羽化的素材；不允许 stage 背景 + 人物场景图叠加。
- 只采用仓库现有 assets/v4 的原始完整 CG：crew_headset / pov_badge / girl_singer / stage_piano / lin_camera / gu_email / usb_case / usb_hand。禁用所有 scene_* 羽化拼接图片。
- 取消 director-v3、director-v4 和它们的 CSS 在构建中的执行，单一 director-v5 负责呈现；保留 mobile-reader 的原始 source-row 锚点、存档及分页测量。
- 第一夜在 6 次对白推进后出现三种真实行动（canon / rescue / investigate），四位女主不再以卡片题目一次性出现。未读的开场原文仍在 DATA 历史中，不篡改原著因果、结局、状态和选择 ID。
- 工作牌是第一视角完整事件 CG，“查看工作牌”关闭后不得提前推进剧情。
- 手机对话层一般不超过屏幕四分之一，大字允许三分之一；一次一个说话者，禁止对白内容内部滚动；所有选择要保持触摸区域不小于 44px。
- 角色立绘素材不是有透明通道的立绘，绝对不能把不透明的人像作为透明人物层叠在另一张背景里。暂未有专属 CG 的 228 场内容保留单一场景底图作为 fallback，不冒称已逐场完成商业级美术。
- 工程自动化负责命令、存档、选择和几何；美术 QA 另须检查完整构图、衣着/道具/场景一致、人物神态和图文一致性。真实用户 30 秒留存暂无证据，不能把“6 次推进”当作“30 秒留存通过”。
