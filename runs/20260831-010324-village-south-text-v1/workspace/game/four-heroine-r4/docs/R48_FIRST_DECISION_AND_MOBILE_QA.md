# 《攻略美少女》v4.8｜首屏可读性与手机三选体验

## 为什么要改

v4.7 的第一道命运选择在 320×568 等短屏上，底部三个固定选项虽然可以点击，却挤得玩家很难看见最后一段真正有因果的信息。截图还显示：大段标题与提示重复，最需要玩家关注的「我知道自己第七天会被清退，要不要改变原著」反而躲在阅读区滚动下方。**能点击≠读懂后愿意选择**。

## 实际接入内容

- **原著不删**：原来的 28 段穿书经过、七次「继续阅读」以及读到最后才开放的三项选择全部保留；不另开「选择页」，不修改任何一个剧本 ID、场景迁移、Guard、效果、结局或存档版本。
- **文字和按钮仍同屏**：最后一页自动定位在末尾真正的剧情悬念；前面同页的原著回忆与 U 盘线索可以上滑回看，不需要额外的「进入选择」点击。
- **短屏优先阅读**：首个决定时让底部故事面板占更多屏幕，320×568 也能同时看到关键结尾、三项完整可点击按钮；平时对话不强制变成满屏网页。
- **视觉更有事件感**：唐映雪正在等待救场，第一处选择时露出她的原创候选立绘；移动到正确裁剪位置，不让角色只剩头发、眼睛或被文字挡住。
- **去掉无效重复**：删去最后一页冗余的纯展示大标题、重复的内心独白和促销式提示，保留真正在当前页发生的正文、时间提示与三项选择。
- **读档兼容**：正式 STORY.json SHA-256 仍为 `fae2d536b2b2a12436d0f39cf7a40abe516cde13a87c4295662ecba181dedbf8`；UI-only 更新，不使 v4.7 记录失效。

## 可复现工程证据

`tools/test-v48-first-choice.py` 在五种手机竖屏视口验证：
320×568、360×780、375×812、390×844、430×932。每种都用真实 Chromium touch 点击读完全部引导、确保最后一个剧情 beat 至少 45px 可见、三项选项同时完整显示/单项高度至少 44px、页面不横向溢出、回看旧正文不记新命令、菜单往返保持滚动位置、最后一次选择只产生一条合法命令。三项不同开局均有真实选择记录。
