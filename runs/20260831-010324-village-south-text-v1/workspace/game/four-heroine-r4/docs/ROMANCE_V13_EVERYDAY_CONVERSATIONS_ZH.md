# 《攻略美少女》V13｜四位女主的日常戏：把论文腔改成人说话

## 范围与真实状态

本轮直接接入 H5 播放器，不改 `STORY.json` 或 `engine.mjs`：唐映雪、沈清辞、林见月、顾晚棠每人 9 场，共 **36 场**（`t01–t10/s01–s10/l01–l10/g01–g10`；原 V11 已重构各人的 `03` 恋爱关系确认场）。人工逐句修改 **86 条**实际演出对白／旁白、**112 条**行动选项、**14 条**关键负面/脆弱时刻的回应。另外修复了旧播放器**决定前的最后一句被隐藏**的问题：现在显示于实际选项上方，不添加假决定或滚动阅读层。原 228 场、751 个正典选择、24 个结局及每个选择的 flag 都不动。

### 改稿的硬性约束

- **一个人只说一小段**。录音室、路边小店、便利店这些现实场景，不能由旁白讲四句话解释一段感情；先给现场动作，再让当事人说话。
- **女主不是无条件爱玩家**：唐映雪的选择始终围绕自己音乐，沈清辞会累也会犯错，林见月不接受为了吃醋改剪辑，顾晚棠会追问现实利益和道德上的过失。玩家不该靠“最懂你”或谎话无代价通过。
- **明确的恶劣行为不能洗白**：`s02/promise` 没钱却空口保证、`t02/fan` 造假粉丝经历、`s06/dismiss` 和 `g06/deny` 隐瞒事实、`l06/ban` 限制旧友电话、`l07/control` 控制摄影剪辑、`g02/leverage` 借材料威胁——原引擎保留对应后果。按钮用明白话提示明显谎言，不搞模糊道德评判。
- **只动呈现，不动命令**：所有选项保留 `data-choice`、原 `id`、原 revision token、engine.effects。若原场景或逐字 hash 将来改变，V13 自动跳过相应那一行，不拿旧文案覆盖新的正式剧本。
- **美术不冒领完成**：现有 V8 通用舞台 CG 与录音室、便利店等私人场景仍不符；这一轮修的是已承诺的真人化文案。36 场需要独立的现实场景背景/事件 CG 的质量门禁仍是 **BLOCKED**，不要把同一张空舞台图宣称足够沉浸。
