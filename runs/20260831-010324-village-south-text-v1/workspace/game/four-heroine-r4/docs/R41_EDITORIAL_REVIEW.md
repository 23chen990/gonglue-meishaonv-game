# 《攻略美少女》r4.1 人物与开局精修复查

**类别**：编辑性正式源修订，不是新故事蓝图。**目标**：前20分钟阅读体验（时间目标，非真人实测用时）；四位女主主观吸引力和声线辨识度。

## 审查方法与证据边界

- 实际读取 r4 正式 JSON 的 225 个场景及初见、开场、续约、个人线的关键选择；修改 **63 个结构化显示字段、32 个场景**，原始 ID/说话人/条件/效果/路由未变。
- 五种首演首选都能够由玩家实际决定；首次心动与私密邀约之间仍有当事人自己的条件和拒绝权。
- 试阅是本轮编辑人员模拟玩家进行的内容审查，不是独立真人盲测；不能证明首30秒、3分钟、20分钟留存。
- 参考了自建 Skill `romance-story-editor` 的人物辨识、自然化、因果/边界审查流程；没有使用第三方作品对白或美术资源。

## 四位女主差异性及未解决的可玩层风险

- **唐映雪**：对旋律专业有主见，会用表演细节调侃而不是只夸许照；有创作、版权、冷饭盒和独立试唱的自主问题。风险：初夜试听邀约是否过于快，真人仍需判断。
- **沈清辞**：高压制作人，先看工作细节、愿意放空五分钟，主动边界明确。风险：旁厅、审批、排期容易堆术语，需监测玩家是否把恋爱当工作单。
- **林见月**：看片时敏感、话不多，注重当事人授权和自有作品。风险：早期“摄影伦理”可能压过情绪回报，需确保可见的温柔和幽默。
- **顾晚棠**：谈条件不躲避，也允许私人约饭；对权责与自我选择有边界。风险：过多“核邮件/赔偿责任”会影响魅力，需要真人考察。

## 决策原则

1. **先真实性、再甜度**：一场救援只能产生好奇和继续接触的机会。
2. **每条路线必须有主动行为**：不只回应男主攻略，还要主动提事、邀约、拒绝、改变日程。
3. **不以恋爱覆盖事业/文件事实**：许照救场不获得现成授权，陆景行不失智，朋友路线不强推爱情。
4. **不冒充可测数据**：有脚本覆盖不等于情绪回报成立，需真人直接试玩与复盘。
