# 《攻略美少女》v4.9｜中性偏男性向的剧情逆袭精修与选择因果审查

日期：2026-10-14。基线：PR #9 的 v4.8 HEAD `10a9f25eb4e94893bb25b2c22d84025efb518ae5`。

## 1. 产品定位与叙事标准

- **不是女性向恋爱文字游戏。** 玩家扮演穿书成为炮灰许照的人，卖点是知道原著但必须亲自动手取证、反击甩锅、争到署名和下一份机会；与四位成年女性的轻恋爱、合作和冲突是复合体验，不把任何角色变成战利品。
- 第一分钟明确「七天后被冤枉清退」，角色真的醒到舞台，知道救场蓝标盘的位置；先看到有代价的主选择，随后马上看到敌方动作、同伴即时反馈。
- 需要爽点，但不靠虚假万能主角：专业音频由阿衡操作，证据需要权限和授权，陆景行是会主动竞争的对手，四个角色保有独立行动和决定权。
- 不是让玩家按 751 次按钮。重点是每次选择后明确展示动作、对方反应、证据/机会/关系变化，重要决策必须影响真正的后续条件；纯结局口吻或收束选择不能伪装成重大分叉。

## 2. 本轮实际编辑

**正式剧本** `data/STORY.json`，逐条反向可还原清单 `patch/v49_story_punchup.json`。影响 28 个关键场景：158 条正文及即时回应、68 项选项、26 项场景标题；共 252 项修改。保留 228 场、751 原有选择、24 主结局、28 段必读穿书引导。全部条件、命令效果、选择 ID、后继和正式结局规则保持原样。

- 穿书开场：从「七天后替人背锅」切入，手机失去、工牌确认、蓝标盘线索、陆景行即将钢琴救场，三条行动路线均写清收益与风险。
- 第一夜反击：签字拆责/请证人/先要副本；程放撤回删档消息；抢先救场须真实试听、切换；“照原著走”仍能通过时间线对抗后续风险。
- 第二日至第六天：唐映雪歌曲署名及热度、沈清辞旁厅的经营风险、林见月未寄的申请、顾晚棠签字责任，形成可执行的行动和权衡，不是一路送礼刷好感。原男主的舞台也会前进，而非站着给玩家踩。
- 第七天/第八天：原著假字幕重现，只有曾真实取得的材料才能解锁合法反击。当场更正后才会产生原著之外的项目询价。没证据的路线无法凭看过小说获得完整胜利。
- 校对：修正群聊同义重复、内心独白人称混用、以及「原著之外第一次出现名字」的时间事实错误。

## 3. 80% 有意义选择的证据边界

从当前 `data/CHOICE_CONTRACTS.json` 检查 751 个正式选择：674 项具有至少一项可追踪的**后续代码读取**（89.7%）；其余 77 项多为结局末尾的口吻、收束、休息等即时反馈选择。这个数字只是依赖分析，**不是 89.7% 的玩家都认为有意义、也不证明 674 项在每条路线都会生效**。

新增 `tools/test-v49-consequences.mjs` 实际使用正式解释器在 17 个重要场景测试 62 个可选行动：同场景的不同合法选择确实产生不同的持续事实或分叉。其中，在“照原著+签错责任+不保留证据”路径，到第七天只能选择退场；在真实收集证据路径，可使用当众、联合和幕后不同反击策略。这是可复现的**因果**，但终局喜好、行动节奏和是否足够爽仍待真人盲测。
