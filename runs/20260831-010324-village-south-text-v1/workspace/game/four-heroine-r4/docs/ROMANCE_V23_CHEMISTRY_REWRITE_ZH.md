# 《攻略美少女》剧本吸引力审查与本轮改稿

## 结论
目前的问题不只是“不够口语化”或“文字太多”。更关键的是：玩家投入了一次选择，却常常只得到一段礼貌解释；很少遇到只属于这个女孩的小事，也很少得到下一次想见她的具体理由。这是本轮的编辑判断，不是陌生玩家实测结论。

V22 已取消风险副标题，方向应保留。不能以“让人看懂”为理由，把选错会怎样重新写回按钮，也不能把每次关系变化都说成道德判断。

## 发现的问题与依据

### 1. 有趣的中间过程被播放器剪掉了
源故事的 t01 分盒饭有最后半块鸡肉、两人分着吃、下次再来等细节。但 V17 起的选后摘要偏向取第一句角色台词与最后一行，常把建立关系的动作留在了未展示的中段。结果不是精练，而是人物少了一次能被玩家记住的举动。亲密场景也会遗漏牵手、放下相机、试探着靠近的过程。

**修改：**44 场逐选项人工写出具体反应，不再从任意首尾句拼摘要。144 条正式选项对应 276 段回应，保留 47 个必要的已发生动作提示。动作提示只是暂缺 CG 的短过渡，不声称已经制作了对应画面。

### 2. 玩家像免费顾问，女主像需要处理问题的同事
初识与后续很多情节都围绕责任单、授权、署名、合同、邮件、场地预算。题材可以保留，但缺少“她在没有工作需求时仍然想见我”的证据。若每次见面都先问“你怎么看”“我该怎么办”，玩家很难期待下一次邀约。

**修改：**初识四场先给人际吸引力；日常里增添女主自己的小愿望和主动靠近。映雪留半首试听、叫玩家没事也可以来；清辞把工作手机放下陪着胡闹；见月接受换到镜头前、留一张糊照片；晚棠在娃娃机前笑出来，愿意去不用刷门禁的小店。不让她们为了奖励玩家失去自己的工作与决定权。

### 3. 四位女主的说话结构过于相似
不少选择都通向“我听明白了—慢慢来—说清边界”。这在个别关键场合合理，连续出现就像换姓名的同一位角色。只有身份不同，不等于相处感受不同。

**修改：**唐映雪用歌、食物和坐在前排的约定连成线；沈清辞工作能扛，私下却愿意陪你装椅子坏了，从工作电话里偷出自己的时间；林见月爱拿镜头逗人，真被拍反而不自在；顾晚棠谈事利落，生活里会输给一只夹不到的猫，也会第一次没备好话。

### 4. 矛盾多，愉快相处与相互惦记太少
旧稿频繁确认是不是还在见别人、是否尊重决定、承诺是否兑现。并非这些不能写，而是每次相处都在解释关系，就没有关系本身。普通玩笑、笨拙、小偏爱不需要全有惩罚。

**修改：**保留隐瞒、控制、空口承诺等真正会产生冲突的分支；普通回答允许幽默、共同体验和不同程度的亲近。拒绝用人物的停顿、收回耳机、合上电脑来体现，不另加“你做错了”的评语。

### 5. 信息与动作不一致会让暧昧变成误操作
t05 靠近听歌的旧按钮实际写入 kissed_t=true；t02 坦白选项说了小说，正典却只记录部分来历；某些首夜台词在音乐切换前已经宣布救场成功。

**修改：**接吻按钮直接写“想亲你。可以吗？”，不是添加风险提示；t02 保留部分透露，t06 才按原行为交代书的事。已经听过穿书说法的路线不会重新装作第一次听。救场只有原引擎实际切换后才算成功。g07 获得说明证据的选择保留对方同意及录下完整说明的可见事件。

### 6. 首夜同一选择的回应播放了两遍
旧流程常先逐页播放原长回复，结束后又播放精编结果。重要人物反应因此来得晚，还显得重复。

**修改：**现有带引擎效果校验的首夜反馈直接出现在选择之后；完整版仍在历史中。没有偷加命令、跳过真正选择或提前改变胜负状态。

## 实际范围与结果
本轮已改 44 场：四场首夜私下交流、四场正式约会确认、36 场个人生活与恋爱剧情。保持原选项 ID、可用条件、关系标志、存档历史与结局引擎；未声称把全部 228 场改完。

本地 Chromium 已逐条点击 143 个源剧情可达分支，全部通过，三档手机视口检查台词完整、选择可点、实际引擎输出与独立预期相同。四条路线从空存档到 R_t/R_s/R_l/R_g，分别保留 94/94/95/95 条真实命令，全部通过结局存档恢复。实际总点击为 373/366/374/373，最长连续“继续”为 11/9/11/9。主线工作占比偏高、其他旧场景的长篇叙述、结局前节奏仍有进一步调整空间，不能把能跑通等同于有吸引力。

## 测试边界
原始 STORY.json SHA-256 保持 84842ca69a861849f16b20d72b4b45421675ea5a934cad51d5f7866e703acf93。静态检查覆盖 44 场/144 个源选项/276 段回应；由原引擎真实重放生成 143 个分支样本，不注入理想恋爱状态。t05/ordinary 在当前真实路线样本中不可到达，保留条件但不冒称浏览器已覆盖。

本地容器只进行了 Chromium 离线加载与模拟 localStorage，HTTP 导航受环境阻止，没有绕过。HTTP 和 WebKit 由当前源提交的 GitHub CI 再检验。精简源码包排除了历史审校文件，本地 npm verify 因缺失该文件不能完成；未伪造审校记录。完整仓库 CI 承担该项验收。旧 V19/V21 精确台词合同使用显式 qa=v22，当前默认的 V23 由新增全部分支和四条完整路线独立检验。

自动化和截图审查不能证明陌生玩家觉得有趣、愿意充值或留存改善。

## 仍然影响吸引力的明显缺口
餐馆、录音室、门廊、吃饭时仍可能显示同一张舞台立绘。文字说分鸡肉，画面却举着麦克风，天然削弱亲密感。这次没有假称修好了美术，也不会把加滤镜称作新 CG。正式场景图、跨镜头人物一致性、商用素材审核和真实手机/首次玩家试玩均未通过。Draft PR 不合并、不发布。
