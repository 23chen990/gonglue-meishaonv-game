**结论：8/8 现有原图均未达到新定义的 P0 竖屏 CG 尺寸/宽高比要求。** 这并不是说这些图片完全不可用作资料：可以做角色外观、色调或“手牌是什么”参考，但不能再把它们放大当最终的剧情主舞台。

重点计算：以 390×844 手机、25% 底部对白区计算，主舞台约 390×633。工作人员原图 909×828 要 `cover`，显示区域宽度约 510px；整个原图的约 44% 横向内容被裁。高 DPR 手机上这个约 510×828 源纹理还要覆盖约 1170×1899 物理像素，因此模糊、脸部过大是可预测的，不是简单的 CSS 字体问题。

**前版效果图**（1024×1536、3×4 网格）每格约 341×384px，并且文字、按钮已在同一张图里，**只能作为构图基准，不允许裁格充当高清 CG**。要得到接近概念图的游戏画面，必须根据每个格子的构图**独立重新生成一张新的高清、无 UI 图像**，将真实 HTML 对白/选项盖在画面前方，再实际截图检查。
