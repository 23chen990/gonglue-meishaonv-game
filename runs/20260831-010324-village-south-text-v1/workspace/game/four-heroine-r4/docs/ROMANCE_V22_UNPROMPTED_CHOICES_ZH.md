# 《攻略美少女》V22｜不要过度提醒玩家

## 竞品对比

《Our Life: Beginnings & Always》的玩家选项展示“想表白／还不确定／有点害怕／暂时不愿说”等当下可执行的表达，并不逐项附带后果预测。真实截图：https://steamcommunity.com/sharedfiles/filedetails/?id=2401199613 。

《未定事件簿》的调查选项让玩家直接点击询问、线索或证据。参考截图：https://minireview.io/adventure/tears-of-themis 。

《恋与深空》的公开剧情记录中也可以看见角色真实说话或提出问题的选择，剧情通过角色回应展开。参考：https://loveanddeepspace.wiki.gg/wiki/Moodscape_Pick 。

以上不是断言所有同类游戏永远没有提示，而是说明默认互动不应替玩家剧透“这个选项会失去什么”。

## V21 的问题和本次实改

此前 18 场关键剧情共有 79 个正式选择，**79 条全部有 risk 元数据并实际显示在选项下方**，例如“她可能会继续自己的生活”“你已答应只和唐映雪交往”。即使玩家还没点击，界面也像策划评审一样解释可能的得失。有历史恋爱承诺时，主角还会被强制加一屏心声，提前说自己“就是骗她们”。这让误会、失言、错过等本应事后发生的戏剧性被说明文字抢走。

V22 实现：
- 普通选择按钮**只显示一句行动／回应**；79 条 risk 仍只保留为内部编辑元数据，不在 H5 中渲染；另用 CSS 隐藏旧版可能残留的 secondary risk span。
- 删除基于旧独占承诺的动态风险预测函数和主动道德训话。原 active/scope/commitment flags 全部保留，允许玩家失信，也保留它对后续真正剧情造成的影响。
- A7a 结局前的 0/1/多恋爱状态选项变成“约她见面／暂不回复消息／逐个结束约会”等操作，不出现“接受关系变冷”“必须坦白”的后果提示。选后照样呈现后果，不会一律得到正反馈。
- 过去选项占两行所以只显示 2–3 条；去掉第二行后，按手机高度计算单屏 2–6 条容量。常见 390×844 的五选项可以全部同屏，小屏保证至少 44px 触区。
- 移除序章旧版页面的“选择会改变后续事件”“没有倒计时”等重复教程小字，保留穿书背景、真实事件起因、角色对白和存档错误提示。
- V11 UI 保存版本 v1→v2，旧阅读游标重置以免跳过新对白；已经执行的正典命令和选择后的角色反应不变。STORY.json 与 engine.mjs 无改动。
