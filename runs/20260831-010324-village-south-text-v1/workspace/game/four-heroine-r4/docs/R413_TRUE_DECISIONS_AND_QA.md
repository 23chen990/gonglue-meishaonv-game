# 《攻略美少女》v4.13｜真实两阶段剧情选择与 QA

本轮解决 Issue #3 指定的 **16 处 5–6 候选的真实剧情决策**：`A2a`、`A3a`、`A3b`、`t03/s03/l03/g03`、`A4a`、`A5a`、`A5b`、`A6a`、`LU_MOVE2`、`A7a`、`H_glst`、`EXEC_s`、`EXEC_l`。不再通过网页翻组掩盖超过四项的真实决策。

## 玩家实际感受到的变化

每次先看到 2–3 种**态度**，点击后主角/当事人会有具体回应，该步是解释器真实的 `intent:<名称>` 命令，记入历史、存档、回退。下一幕不重复刚才的长旁白，只开放该态度之内已满足条件的原始具体行动（通常 2–3 项，最多 4）。每次可以在历史里回到态度之前，重新选择不同方向。

第一步**不**凭空获得证据、好感、约会、同意、资源、时间或进度。第二步仍由原 `STORY.json` 的行动 ID、条件、效果、后继和人物自决规则执行。因此保留 228 场、751 个原始动作、24 主结局、28 段必读穿书经过。日程安排的大量动态可选活动是单独的导航问题，仍经过分类菜单；不能混称为上述新增剧情命令。

## 历史记录与兼容

历史版本保存的真实选择按原有记录合法重放，进入新剧情时启用两阶段；已经在新格式保存的命令用 `uiSchema=v4.13-true-decisions` 和 `legacyPrefixLength` 标记老历史前缀。老前缀只能在迁移边界之前允许，不可借旧档越过当前两阶段流程。未知哈希、无效历史和失败保存仍保留原始记录与导出机会。
