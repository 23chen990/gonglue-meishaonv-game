# 《攻略美少女》V15：新人认知与第一次见面

## 这次解决的问题

V14 恢复了“现实看小说 → 进入北岸 → 点击工牌 → 知道第七天背锅风险”的顺序，但调查分支仍曾出现：**主人公还没认识林见月、顾晚棠，选项却直接喊她们名字去帮忙。** 后面多处也把公开群邀请写成四位女主私下主动约会，让第一次游玩的玩家感觉自己已经在这里生活了很久。

## 已修改的实机内容

1. **找人前，先看得见她在做什么**：调查选项用“侧幕拿相机的人”“负责授权的人”，不需要提前认识姓名。
2. **第一次接触才出现姓名和职责**：玩家选择摄影后才由林见月自报名字；选择授权后才由顾晚棠说明她负责什么。名字第一次出现就是一次真正的互动，不是人物百科弹窗。
3. **已经认识，就允许自然叫名字**：如果之前确实一起留下视频/查过邮件，下一次找人时选项会写“林见月/顾晚棠”，不再假装不认识。用正式引擎中的 `source_pre_switch_timestamp`、`source_programme_approval_note` 判断。
4. **救场分支不要偷放没解锁的人物**：玩家直接救场时只能联系真正可用的唐映雪、沈清辞和阿衡。不会为了显得“四女主齐聚”开放陌生人的不真实选项。
5. **11 处关键场景台词修正前置认知**：热搜主角用“昨晚弹钢琴的陆景行”；赞助方、主办方直接说身份；第 4 天四条信息是公开项目群邀约，而不是四个早就跟玩家熟悉的人；第七天回想“第一夜”，不再错算成“七天前”；第二十一天仍牢记自己是穿书者。

## 工程合同

- 不增加假选择、好感值或脱离真实原引擎的结算。
- 不修改 `STORY.json` / `engine.mjs`；已存在的 228 场景、751 选项、24 个结局和旧存档语义不变。
- V15 新增 4 条实际人物接触路径，每引擎 4 条；与原先 V9–V14 完整回归一起跑。
- `tools/test-romance-v15.mjs` 校验角色身份前置、11 条变化、18 场/79 个正典映射和原始 story 哈希；`tools/test-romance-v15.py` 验证真人点击、已认识与未认识的不同措辞、实际的原引擎选择记录。

## 仍需实际产品验收

这只解决叙事上的“我为什么知道这个人、这件事”问题，没有补齐咖啡馆/约会等 36 场的地点匹配 CG，也没有替代高清商用美术审查、真实物理手机触控或首次玩家理解测试。不能把浏览器自动化通过等同于玩家认为好玩。
