# 《攻略美少女》V19｜因果先行的恋爱对白重构

## 为什么 V18 仍让第一次玩的玩家摸不着头脑

上一版把「每场两句就有选项」当成硬指标，技术上做到，但常常删掉了玩家**为什么在这里、刚才做了什么、女主为什么突然追问**的前因。36 场日常中曾有 26 场编辑素材只有旁白；V18 把它们改成了人物自己说话，却没有把旁白承载的核心事件移到画面。真实 CG 还复用舞台背景，进一步放大了错位感。

不能再用字数数量替代剧情理解。V19 对每场按「具体地点和可见动作 → 女主基于这个动作开口 → 玩家自己点击回应 → 原引擎真实回报」重新导演。

## 实际修改：36 场逐场改写

- 36 场都有**地点 + 眼前事件**的短场景字幕，避免突然在未介绍的地点开始对话。字幕只在阅读对白时显示，做选择或看回应时自动收起。
- 36 场共有 **88 段**按剧情需要的单人短对白，允许 2–3 个说话回合，不再死守「两句」；只有 t02 一处必要的主角内心惊讶，其余主角公开说出口的话均由玩家点击原有真实选项，不由播放器替玩家自动说。
- 对有关系史的剧情，新增 **14 个带原故事 row ID/speaker/textHash 校验的回调候选**，在真实存档的相应前情存在时最多播放其中一句，不向无关路径泄露秘密，也不凭空发明女主已经知道的事。
- **9 条**原有按钮文字与事件对齐，如「我在书里看过旧版本」「我只拍关东煮」「我想去河边走走」；选择 ID、条件、引擎效果、原 228 场/751 个底层选项和结局规则均不改。
- 特别修复「你刚才说了句哦」这种主角根本没由玩家点击说过却被角色当作既定事实的台词。林见月现在根据画面里玩家的沉默和神情来问，而不会代玩家说话。

## 四处真实的 Before → After

| 场景 | 被剪断的因果 | V19 处理 |
|---|---|---|
| t02 唐映雪录音室 | 主角莫名会唱未发表旋律 | 试听半首 → 主角意识到书的番外谱子暴露 → 她追问没录过的音 → 玩家选坦白/谎言/暂时解释不了 |
| s06 沈清辞吃饭 | 女主突然审问有没有其他人 | 先看见主角频繁看手机 → 清辞明确表示不查手机、只问是否还在约会 → 如果确有映雪合照，她才提合照 |

## 保留和迁移

- 正式 source guard 不只检查 scene ID，还校验源正文行 hash；源剧情修改后自动回退上一版演出，而非错套旧话。
- 原按钮、后果和刷新仍复用同一引擎。V17/V18 旧阅读游标按版本迁移到新版首句，不跳过新背景；已经点过的剧情命令和选后真实回应不会被重算。
- `?qa=v18` 允许工程师回归上一版人物两句对白，`?qa=legacy-reader` 保留原始逐页正文的对照入口。**用户默认路径**是 V19 的因果优先演出。

## 工程测试与明确未解决的问题

新增 `tools/test-romance-v19.mjs` 静态合同和 `tools/test-romance-v19.py` 真实 HTTP Chromium/WebKit 36 场回归，验证字幕不遮挡、单人对白、不滚动、不缩字号、选项真实可达、有害/诚实行为仍走原引擎、旧档案重开。保留所有原有 V13–V18 测试，通过 CI 后才记录最终状态。

**不能宣称完全解决剧情品质：**目前录音室、便利店、餐馆和雨夜仍复用同一批 1024×1536 工程舞台人物 CG，这与实际地点不符；原 228 场并非全部重新编写；正式商用美术授权、iOS/Android 实机和 8–12 位陌生玩家无提示盲玩仍是发布门槛。PR 保持 Draft，不合并、不上线。

## 第二次文案审校（看完真实手机截图后）

原故事中 t02 的章节标题是「你怎么会没发表的歌」，语法本身不完整。V19 已在 36 场个人剧情的演出层隐藏这类原始章节标题，以具体的「地点｜发生的事」替代，既不叠两套标题，也避免 AI 腔标题抢走对白重点。没有删除源故事的章节字段。

进一步纠正可直接复现的逻辑穿帮：沈清辞 s07 的活动还是“报名太少”，不能说成“只来了几个人”；顾晚棠 g05 不再认定玩家已经盯着她看；唐映雪 t09 不再默认主角在找自己的名字；顾晚棠 g09 改为直说她担心失去职位后的关系。

第八天 UNWRITTEN/A6b 和第二十一天 A7a、最后一天 A7b 也换成具体的「独立项目／赴约／在谁面前解释承诺／工作与未来选择」，不让玩家对“有人等我”“有些话要说”猜谜。涉及某一位女主是否知道什么，仍按引擎条件写话，不假定玩家同时与四个人交往。所有选项 ID/effects 和官方 STORY.json 不变。
