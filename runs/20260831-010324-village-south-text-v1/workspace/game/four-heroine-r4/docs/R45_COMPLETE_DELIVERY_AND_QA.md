# 《攻略美少女》r4.5 一次性体验与剧情整合交付（2026-10-14）

## 最重要的版本事实

- **这是完整四女主游戏的新版候选，不是几十秒演示样机**。唯一可编辑剧情源为 `data/STORY.json`，HTML、`runtime.mjs`、校验元数据均由 `npm run build` 自动生成。
- 正式旧版：2026-10-14 r4.4 本地工作基线；GitHub PR #2 还未直接包含 r4.3/r4.4。
- 本版保留 228 场景、751 个底层动作、24 主结局、40 命运尾声、8 番外、6 收束；全部四女主组合及单人/独身路径由原解释器负责，不做假关系注入。
- 穿书引导 28 段按原 r4.2 新规范保留，分段阅读结束时**同屏直接给 `canon/rescue/investigate` 三选**；原著信息仍以主角内心独白出现，不能另立系统说明卡。
- **保存到新 key `gonglue:revision-r4.5-portrait:canonical`**；旧 r4.3 / r4.2 浏览器进度独立，不静默迁移。新存档有故事哈希核验及多标签冲突阻断。`ui.choicePage` 只代表不耗费剧情行动的分类阶段。

## 实际已经修改的内容

1. **完整手机视觉小说阅读器**：`tools/vn.css` 与 `tools/preview-ui.js`。固定背景+原创角色画面+底部文字台，阅读区和选项区独立可滚动，窄屏安全区、大字体和减少动画均有覆盖。
2. **去无效点击**：普通剧情不再按字数制造“继续，继续，最后才给选项”分页。`OP_SETTLE -> OP_FORK` 的固定单一过渡在 UI 中预览并合并到同一选择面板；玩家点击真实 `OP_FORK` 选项时，引擎依次合法记录 `continue` 和所选动作，存档及后文因果不丢失。
3. **复杂选项按意义分层**：常规 5–8 个真实候选按谎话处理、靠近或保持距离、作品职业判断等聚类；晚期 `@schedule` 曾有多达 24 个同时解锁动作，改为“找谁 / 书外事件 / 关系变化 / 休息”，必要时向下用细分类别，**每一层最多四个按钮**，不再假装仅用“上一组/下一组”就符合要求。类别点击不产生剧情命令。
4. **候选原创新视觉资产**：`assets/portraits/{t,s,l,g}.webp` 与 `assets/scenes/backstage.webp`。均是本次生成的候选美术，不是竞品截图或盗用立绘；已经在单文件 HTML 中以 data URI 内嵌，可离线打开。正式商用前仍需人工统一美术风格、审视内容质量。
5. **音效和设置**：自制 WebAudio 轻触提示，默认关闭，不会自动播放；菜单可开关。大字、返回、回看、导入/导出、结局收藏及本地存档延续原功能。
6. **剧情改稿 102 项 / 28 场景**：`patch/v45_editorial_patch.json` 包含旧句、改句、`speaker`、`lineId` 和原因。首演、四女主初见、第二天群聊施压、第三天她们主动邀请、第五天影片反转、第七天栽赃与第八天原著之外的未来。修正共用文本错误：原著线没有找到 USB 不能在 A1b/A6a 假定找到了；第 4 天未联系过四位角色，改成项目群开放邀请而非凭空的私人消息。
7. 不改变选择 ID、路径、人物年龄、Guard、效果、位置与结局，文本节拍保留原有结构。抽象职业术语依然是故事背景，但重要转折优先表现角色行为和感受，不再反复给玩家讲核对制度。

## 与现有 romance-story-editor Skill 的关系

参考 `ai-mini-game-factory/.agents/skills/romance-story-editor/SKILL.md`：先证实可达路径和人物知识、再保证自主与关系阶段、再自然化中文、然后检查“选择→行为→反应→后文回声”、最后做 JSON/QA 保护。这个 Skill 是工厂里的工作规则，**不是本运行环境安装成功的可调用 MCP**；不宣称已经自动通过 Skill 全部文学验收。结构测试通过不等于真人喜欢。

## 仍然无法在这个环境中代办的工作

- **REA 对易次元/橙光专有客户端的真实运行时逆向**：应当在具备合法访问权限和 REA Codex MCP 的设备环境中收集具体作品的界面视频/DOM、操作序列与证据，不可把基于公开资料与开源引擎的研究冒充 REA 实录。
- **真实 iOS / Android 及真人盲测**：用户体验受设备掉帧、字体大小、真实注意力和偏好影响，必须由真实对象做；本包附有所有可自动化的门禁和需要记录的测试问题。
- **商业化**：真实广告 SDK、触发策略、缓存重启测试和平台合规需用户提供实际平台及应用信息；现版本无广告强制打断剧情。
