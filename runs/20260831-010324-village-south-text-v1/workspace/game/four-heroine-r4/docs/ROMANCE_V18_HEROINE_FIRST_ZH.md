# 攻略美少女 V18｜36 场恋爱日常由女主亲自说话

## 问题

V17 已建立独立手机 ADV 演出层，但源自 V13 的 36 场日常编辑里仍有 26 场只有事件旁白，没有一句被精修过的女主对白。画面即使换成单人小对白框，玩家也在被动听旁白解释人物做了什么，直到选项才发现自己能互动。此前只是播放器工程通过，并不代表剧情好玩。

## 本次实际实现

- 新增 romance-v18-moments.json：唐映雪、沈清辞、林见月、顾晚棠各 9 场，共 36 条场景动作提示和 **72 句专门编辑的女主口语对白**。每场两句、一句一个屏幕，第二句直接引出原有选择；不新增新行动、好感分或虚假状态。
- V18 导演依原剧情 row id、speaker 和 textHash 验证各场次源身份，源内容不符则自动退回 V17 导演，不套用过期对白。所有选项仍走原 engine.choose、effects、命令历史和 24 种原结局。
- 剧情地点只给一条短动作提示，不再播放连续数屏旁白。使用现有 11 张候选人物／舞台 CG 与轻微光温变化区分雨夜、工作、亲密等氛围，明确在 DOM 标记 **复用人物图，不是假装已有 36 套实景 CG**。
- 对新版的 36 场增加真实 HTTP Chromium/WebKit × 3 种手机尺寸轮替的对话、遮挡、图像、点击、真实选择、刷新与存档迁移回归。原 V17 36 场以及关键有害／诚实选项对照回归全部保留。
- 老 UI 缓存 V17 v1 只重置尚未进行的屏幕游标，保持引擎历史以及已经执行的选项和回应；旧完整原文模式 ?qa=legacy-reader 不受新演出覆盖。

## 质量界限

改的是剧情节奏、女主开口方式与首屏上下文，不是直接把 228 场全部改稿。音画表现仍欠缺对应录音室、便利店、咖啡馆、雨夜等地点的独立正式 CG。商业美术版权、1536×2400+ 原生高清、实体 iOS/Android 真机和陌生玩家盲玩仍未通过，PR 保持 Draft，不合并上线。

新 V18 通过情况必须以本次源代码及其经自动构建机器人回写的 play.html 的相同 HEAD QA 为准；CI 绿色不等于玩家愿意继续。
