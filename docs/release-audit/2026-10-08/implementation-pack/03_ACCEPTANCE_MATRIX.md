# 80 项上线验收用例：真实游戏全部待执行

当前 80 项均为 NOT_RUN；这不是测试通过报告。执行前先给每项绑定真实场景 ID、存档或引擎夹具、运行环境和源码 commit。完成后在 reports/game-acceptance.NOT_RUN.json 的工作副本中填写实际结果与证据，并更名为正式报告。不要改写本包自测日志冒充游戏测试。

PASS=实际通过；FAIL=实际不符；BLOCKED=环境或适配受限；SKIP=对应功能确实不存在且有源码证据。SKIP 不能代替未做的测试。P0 阻断发布；P1 必须修复或明确移出发布范围；P2 可记录局部风险。

表中的“引擎”指项目真实引擎，不是只执行本包示例。涉及全量发布场景、选项或结局的条目不得只抽一个代表就算完成。审读属于编辑证据，不是实际玩家验证。
