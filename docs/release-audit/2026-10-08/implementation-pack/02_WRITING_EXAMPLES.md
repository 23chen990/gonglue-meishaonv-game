# 原创改写示例与完整分支练习

本文件所有人物、对白、坏例句与场景都是本次新写的教学示例，不是仓库原文，不代表已经修改了真实游戏。正式替换必须先读取原作事实与人物声音，不能把示例当新设定塞进去。

## 一、十类表达问题怎样具体改

### W01｜把抽象情绪换成有对象的动作

合成坏例句：“她眼底掠过一丝难以言说的复杂情绪。你忽然明白，她需要的不是答案，而是一场温柔的救赎。”

新写法：“她把申请表翻了个面。‘先别替我交。上面那个人，不是我想写的。’”

用动作和请求交代当前矛盾。原作没有申请表就不能硬加；使用已经出现且有作用的物件。后续选项围绕询问、等待或执行请求，不继续解释她多么复杂。

### W02｜沉默可以保留，但要发生变化

合成坏例句：“沉默在两人之间蔓延，仿佛有千言万语，却又谁都没有开口。”

新写法：“你没接话。她把第二把椅子拉近了一点，坐下后才问：‘你是不是也觉得我不该去？’”

沉默之后出现可回应的问题。不是每段沉默都必须解释心理，也不要反复用“气氛变得微妙”代替互动。

### W03｜安慰不是替别人总结人生

合成坏选项：“告诉她，她从来都不是一个人。”

新选项：“问她今晚需要你留下，还是明早再来。”

一种回应：“‘今晚。’她停了一下，‘但不用说什么，陪我把这些装进箱子就行。’”

其他回应由真实人物决定，不保证所有角色都喜欢这种问法。关键是将需要说清，让对方有决定权，不把一句安慰当万能加分项。

### W04｜选项不能偷换授权

合成坏例：选项是“支持她”，后文却让主角擅自替她答应公开发言。

新选项方向：“先问她愿不愿意上台，再决定怎么帮。”“告诉组织者，你们还需要两分钟商量。”“只把流程讲清楚，不替她作决定。”

不必把三项都放在一场戏里。若保留“替她答应”的越界选择，标签就写明该动作，并给相符的后果，不把越界伪装成支持。

### W05｜避免善良、愚蠢、邪恶三选一

合成坏选择：“温柔安慰 / 冷漠离开 / 恶意嘲讽”。

新选择：“先陪她处理眼前的事 / 先说明你今晚能帮到哪里 / 提出另一种做法，让她决定”。

区分行动方式与代价，不必让三项道德等价。尖刻路线可以存在，但需符合可扮演的主角范围，不能只为凑数量。

### W06｜暧昧来自具体相处，而非金句

合成坏例句：“如果你是黑暗里的星辰，那我愿成为守护你直到永恒的夜空。”

新写法：

“你连我不吃葱都记住了？”

“上次你挑了十分钟，饭都凉了。”

她笑了一下，把菜单推回来。“那这次你点。只限这一顿。”

前提：本路线真的发生过共同用餐。没有这个前史就不能硬写“上次”。吸引力来自记忆、接纳和带边界的回应，不是单方面高强度表白。

### W07｜道歉不等于立即恢复

合成坏例句：“听完你的道歉，她的委屈瞬间烟消云散，好感大幅提升。”

新写法：“我知道你在道歉。”她把文件拿回去，“这次我自己交。下次要替我做什么，先问一句。”

后续给一次可兑现的小机会。道歉与重新建立信任分开，不凭一句话直接解锁亲密结局。

### W08｜悬念要给可行动的信息

合成坏例句：“有些事，你以后自然会明白。现在知道，对你没有好处。”

新写法：“电话里不方便说。明天十点，我会去把那份记录拿出来。你可以一起去，也可以等我回来。”

仅当人物确有不能立即说明的理由，且时间、地点、记录与原作一致时采用这种结构。否则让角色现在讲清楚，别人为制造误会。

### W09｜拒绝也有完整故事

合成坏例句：“你没有陪她，错过了唯一机会。失败。”

新写法：

“那就下次。”她把多拿的票收回去，“明早的事照旧？”

你确认了时间。她点点头，先走了。

取消本次邀约，不取消已经成立的合作。不因为正常拒绝羞辱玩家，也不偷偷让主角已经参加邀约。

### W10｜结尾回应行为，不贴评价

合成坏例句：“你们终于学会信任，懂得真正的陪伴是双向奔赴。”

新写法：

她把下一次的排班表放到你面前。

“这回我先问。周六，你有空吗？”

你看了眼时间。“有。地方你定。”

前提：前文围绕替人作主和先问意见发生过冲突与修复。没有这条因果链，这段也只是空泛甜蜜。

## 二、完整的十节点演示

文件：`examples/synthetic_scene.json`。这是两位成年合作伙伴准备小型演出的独立练习，不是原作章节，也不意味着原作角色已经成年或从事演出。

目标：让先问、代替决定、先核实有不同回应；道歉需要后续履约；拒绝留下不自动变成坏人；借用物件的交接有真实结果。没有好感总分。

状态：consulted=已询问意见；apologized=已为代替决定道歉；promised/kept=承诺/履行；plan=处理方式；item=转接线持有与归还状态。

START：主持人要求临时缩短演出。选择先商量、替她答应，或核实可用时间。

ASKED：她提出删去结尾重复部分。玩家承诺帮忙，或明确只负责设备。

BOUNDARY：她指出自己没有同意被代表。玩家承认越界并重新问分工，或坚持已经替她处理。道歉尚未完成关系修复。

CONFIRMED：主持人再给一分钟协商。玩家带回信息、一起处理，或说明自己的边界。

WORK：承诺留下的人实际履行，或及时说明无法继续。后者不会被标记为已履约。

AFTER：履约后才进入散场交谈。玩家归还物件后可以提出吃饭，也可以结束当晚。接受邀约不等于恋爱关系已经成立。

SEPARATE：没有参与后半段的人在散场后交接物件。当面交还得到正常收束；不交还就离开，会收到追还信息。

END_MEAL：双方约好吃饭，回指先问意见的方式。

END_COLLEAGUES：正常结束合作，不捏造没发生过的邀约。

END_DISTANCE：未归还物件导致后续交接问题，不是因为拒绝恋爱而被惩罚。

演示不提供真实游戏 UI 或存档，其图模型通过不证明对白吸引力。本文件的 ID 和设定不能混进正式剧情。
